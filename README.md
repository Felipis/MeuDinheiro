# MeuDinheiro 🦒

Site pessoal de finanças, feito em HTML, CSS e JavaScript, sem dependências.

## Publicar

Envie `index.html` para a raiz de um repositório GitHub e importe o repositório na Vercel, usando **Framework Preset: Other** (sem comando de build). Ou envie esta pasta por [Vercel Drop](https://vercel.com/drop).

## Atenção aos dados

- Os registros são armazenados em `localStorage`, associados ao endereço do site e ao navegador/dispositivo.
- Não existe login, servidor, nuvem nem sincronização entre dispositivos nesta versão.
- Dados lançados enquanto o HTML estava aberto pelo computador não migram automaticamente para a versão publicada, pois o endereço de origem muda.
- Use **Fazer backup** antes de mudar de endereço/navegador, e **Importar backup** no novo local, tomando cuidado porque a importação substitui os dados existentes.
- O backup JSON pode conter informações financeiras. Não publique o arquivo de backup em repositórios públicos.
- Evite cadastrar dados reais de bancos, números de conta, senhas ou cartões completos neste site experimental.
